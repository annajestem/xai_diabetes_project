# XAI Diabetes Project

Projekt dotyczy klasyfikacji ryzyka cukrzycy na podstawie danych diagnostycznych oraz interpretacji modeli z wykorzystaniem metod XAI.

## Struktura projektu

- `data/` — zbiór danych
- `notebooks/` — notebook z analizą
- `outputs/` — wykresy i tabele wynikowe
- `report/` — opis projektu / raport
